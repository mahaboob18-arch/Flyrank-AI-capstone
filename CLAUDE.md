## AI Assistant Instructions

Before generating code:

1. Analyze the existing project structure.
2. Create a short implementation plan.
3. Identify files that need modification.
4. Explain trade-offs when relevant.

When implementing forms:

- Use schema-based validation when possible.
- Separate validation logic from UI.
- Handle edge cases explicitly.
- Include accessibility considerations.
- Provide field-level error messages.

Before finishing a task:

1. Verify requirements were implemented.
2. Check for accessibility concerns.
3. Suggest improvements if appropriate.
4. Recommend verification steps such as:
   - npm run build
   - npm run dev
   - manual testing
